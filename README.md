# Billie

Human-backed agent invoice API (Stage 1).

## Stack

- Next.js (App Router) + TypeScript
- pnpm
- World AgentKit (human-backed agent verification)

## Setup

```bash
pnpm install
pnpm dev
```

## Endpoints (Stage 1)

| Method | Path | Auth |
|--------|------|------|
| `GET` | `/api/health` | public |
